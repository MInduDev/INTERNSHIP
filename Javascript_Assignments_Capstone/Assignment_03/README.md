# Assignment 3: Conditional Logic

This assignment introduces decision-making in JavaScript using conditions.
It shows how programs can behave differently depending on a value.

## Learning Goals

- Use `if`, `else if`, and `else` statements
- Apply the `switch` statement
- Use a ternary operator for quick conditions
- Convert a numeric score into a grade
- Check pass/fail status

## Concepts Covered

- Conditional statements
- Comparison operators
- Grade logic
- `switch` case handling
- Ternary operator

## File

- `assignment-3.js`

## What the Program Does

The program uses a score value of `85` and then:

- checks the score range to decide the grade
- uses `switch` to assign the label
- uses a ternary operator to decide if the student passed or failed

## Example Output

```js
Score: 85
Grade: B
Status: Passed
```

## How to Run

This script can be run with Node.js:

```bash
node assignment-3.js
```
