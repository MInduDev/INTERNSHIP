# JavaScript Assignments & Capstone Project

This folder contains the six assignments and the capstone project from the supplied PDF.

## Structure

- assignment-1: Variables, Data Types, Console Operations
- assignment-2: Operators, Expressions, Input Handling
- assignment-3: Conditional Logic
- assignment-4: Loop Control Structures
- assignment-5: Functions and Scope
- assignment-6: Arrays, Objects and Core Methods
- capstone-project: Interactive Product Inventory & Analytics Dashboard

## How to run

### Assignments 1, 3, 4, 5 and 6
Open the corresponding `.js` file in a browser environment or run it with Node.js where browser-only APIs are not used.

### Assignment 2
This uses `prompt()`, so open it through a browser HTML page or browser console.

### Capstone
Open `capstone-project/index.html` in a browser.
The project asks for a product name and price using `prompt()`.

To reproduce the PDF's sample output:
- Product name: Monitor
- Product price: 150
