# Assignment 4: Loop Control Structures

This assignment focuses on loops, which are used to repeat actions in programming.
It helps beginners understand how to repeat code efficiently and stop when a condition is met.

## Learning Goals

- Use `for` loops to repeat code a fixed number of times
- Use `while` loops for condition-based repetition
- Understand the `break` statement
- Create a multiplication table
- Find the first number greater than 10 that is divisible by 6

## Concepts Covered

- `for` loop
- `while` loop
- `break` keyword
- Loop conditions
- Incrementing values

## File

- `assignment-4.js`

## What the Program Does

The program does two tasks:

1. Prints the multiplication table for 5 from 1 to 5.
2. Uses a `while` loop to find the first number greater than 10 that is divisible by 6, then stops using `break`.

## Example Output

```js
-- Multiplication Table of 5 --
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25

-- First number > 10 divisible by 6 --
Found: 12
```

## How to Run

```bash
node assignment-4.js
```
