# Assignment 2: Operators, Expressions, and Input Handling

This assignment focuses on using JavaScript operators and reading user input.
It teaches how to calculate a bill with a tip and display the final amount.

## Learning Goals

- Use arithmetic operators like `+`, `-`, `*`, and `/`
- Convert user input from strings to numbers
- Create expressions to calculate values
- Use `prompt()` to get input from the user
- Display the total bill in the console

## Concepts Covered

- Arithmetic operations
- Type conversion using `Number()`
- Expressions and calculations
- User input handling with `prompt()`

## File

- `assignment-2.js`

## What the Program Does

The program asks the user for:

- the bill amount
- the tip percentage

Then it:

- converts both values to numbers
- calculates the tip
- adds the tip to the original bill
- prints the subtotal, tip, and total amount

## Example Flow

```js
Enter your bill amount: 100
Enter tip percentage: 15
```

## Example Output

```js
Subtotal: $100
Tip Percentage: 15%
Calculated Tip: $15
Total Amount to Pay: $115
```

## How to Run

This assignment uses `prompt()`, so it should be opened in a browser environment:

- open the HTML page that loads this script, or
- run it in a browser console
