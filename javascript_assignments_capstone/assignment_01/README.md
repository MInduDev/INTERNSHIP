# Assignment 1: Variables, Data Types, and Console Operations

This assignment introduces the basic building blocks of JavaScript.
It helps beginners understand how to store values, identify their data types, and display output using the console.

## Learning Goals

- Use `var`, `let`, and `const` to declare variables
- Understand different JavaScript data types
- Work with arrays and strings
- Print values to the console using `console.log()`
- Use template literals to display dynamic output

## Concepts Covered

- Variables
- Primitive data types such as strings, numbers, and booleans
- Arrays
- `typeof` operator
- Template strings with `${}`

## File

- `assignment-1.js`

## What the Program Does

The program declares:

- a student's name as a string
- age as a number
- employment status as a boolean
- a list of skills as an array

Then it prints each value and its data type to the console.

## Example Output

```js
Name: Alice (Type: string)
Age: 25 (Type: number)
Is Employed: true (Type: boolean)
Skills: ["HTML","CSS","JavaScript"] (Type: object)
```

## How to Run

Open the file in a browser console or run it with Node.js:

```bash
node assignment-1.js
```
